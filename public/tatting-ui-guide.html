Property Bar

Appears below the top toolbar when an element is selected. Contents change by element type.

Common Fields (all types)
Notation
Type stitch notation here (e.g. r: 5ds-p-5ds). The element updates live. Invalid notation can be seen under View / Show invalid notation.
Order #
What is the order number for tatting the current element.
RW
Adds "RW" to the end of notation output. When you need to tat on the other side.
Rotate 90 Degree CCW
Rotates 90 degree CCW. Works for single elements and groups.
Rotation angle
Type any angle and press Enter to rotate to that angle precisely. Works for single elements and groups. Also accepts calculations: +15 / -15 (relative), x*2 (x = current value), 90/4.
Rotation Nudge
Use the arrows to fine-tune the rotation to your liking.
Rotate 90 Degree CW
Rotates 90 degree CW. Works for single elements and groups.
Flip horizontal
Flips elements or group horizontally.
Flip Vertical
Flips elements or group vertically.
Notation label offset
Slider controlling notation label distance from the path. Negative = inside the element, positive = outside, 0 = on the path.
Hide Notation label
Toggles notation visibility.
Polar rotation center
Dropdown: pick a polar grid so rotation and flip pivot around the grid's center, or Own center to use the element's own center. Only visible grids are listed.
Material
Dropdown to assign a thread material. Color comes from Material properties. Materials are defined in the Materials panel.
Picot Tools (wand)
Next to the notation box (rings and chains, not split rings). Reverse notation, clear unjoined picots, add picots, fill density, compact repeats and scale — see Help → Features.
Reset
Puts the shape back to default (chain curve / ring squeeze) and sets rotation to 0. Not available for ghosts, lines, or split chains.
Tension
The ring's tension, 1 (tight) – 5 (loose). Use −/+ (steps of 0.5) or type a value. Changing it resizes the ring (one undo step) and becomes your default for new rings. Split rings get a quarter of it; chains, circles, Josephine knots and lines get none.
Round
Dropdown next to Order # — assign the element to a round without entering Tatting Order mode. Lines have it too.
Ring
Shape
Toggle between Circle and Teardrop. Teardrop has a pointed end for depicting folded rings. The third button, Convert to Josephine Knot, asks for confirmation first — all picots and connections are removed and the stitches change from ds to ss.
Squeeze
Stretches or compresses the ring vertically without changing stitch count. Positive = taller, negative = flatter.
Reset (squeeze)
Resets squeeze and rotation to 0. Keeps the element's polar rotation center.
Split Ring
Side A notation
Stitch notation for the first half.
Side B notation
Stitch notation for the second half.
Sq / CA / CB
Three squeeze sliders for split rings. Changing them never changes the stitch count. A Reset button sets them back to 0.
Material A / B
Independent materials for each half. Flipping a split ring keeps each color on its own half.
Line
Core:
How many beads are on the string.
=
Toggle if all beads are the same or different.
Dropdowns
Select the beads from the Bead Library
Copy/cut/paste Beads
Copies, cuts or Pastes the beads on the string.
Order #
Lines can carry a tatting order number just like rings and chains. The number displays at the arc midpoint of the line on canvas and is included in SVG export and pattern output.
Multiple elements selected
Group name / color
Shown when groups are selected: rename the group and pick its color.
Notation
One box that applies to all selected elements. Only available when they're the same type. If any joins would be lost, you're asked once for the whole selection.
A: / B:
For a selection of split rings: one box per side, each applied to every selected split ring.
Rotate / Flip
±90° buttons, a Δ° box (accepts calculations, like the single rotation box) and Flip H / V.
Label offset / Hide label
Same as for a single element, applied to all.
Polar rotation center
Same as for a single element, applied to all.
Material
Assigns one material to every selected element.
Line beads
When lines are selected: paste a copied bead setup to all of them.
Scale
Scales the notation of every element that can be scaled; shows how many of the selection can be.
Tension
Shows the selected rings' tension, or – when they differ. Setting it applies to every ring and split ring in the selection (one undo step) and becomes your default. Also in the group bar.
Reset
Reset transformation for every selected element.

Available Editing Modes

Picot Edit Mode

Entered via left toolbar: Joint Picot Tool, or Shift+J. Exit via 'Exit mode' button or ESC.
In this mode you can select and connect elements that have the joint picot notation.
JP - joined picots, JPG - joined picots with guide point, or BE beaded element, with joined picot setting.
CJ - core join, CJP - core joined picot also selectable and joinable in this mode.

Using join points
  • Circle markers indicate where joining points is possible.
  • Click to select, or drag to multi-select. Purple colors indicate selected points.
  • Yellow circles and dashed lines indicate existing connections.
  • A join's color follows the original picot's element (Auto). To change it, select the join and use the Picot Color dropdown.
  • The first time you enter the mode, a short tip explains how to join; tick Don't show again to hide it.
Mode Banner Row
JOIN
After selecting more than one join picots, this button will connect them together.
Shortcut: J
CUT
Selecting already connected picots, this button will remove their existing connections.
Shortcut: C or DELETE
Fold Picots
A toggle. While it's on, JOIN (and J) makes a folded picot instead of a regular join. Works on two plain picots only.
Picot Color
Shown when a join is selected. Auto, or one of the materials involved in that join.
✕ Exit Mode
Exits Mode and returns to the normal property bar.
Shortcut: ESC
Fold Row (appears when a fold is selected)
Outer / Inside Length
How much thread is on each side of the fold. Hold the − / + buttons to repeat.
Angle 1 / Angle 2
The direction each end leaves its picot, as an angle off that picot's perpendicular (−100° to 100°).
Copy / Paste
Copy one fold's settings and paste them onto another. The copy is kept until you close the app.

Bead Edit Mode — Assigning Beads to Picots

Assign beads to any element containing the BE (Beaded Element) notation. Exception is the Line element, that handles its own beads in the property bar.
Enter with Shift+B or the 'Beading mode" on left toolbar. Exit via 'Exit mode' button or ESC.

Selecting bead positions
  • Diamond markers indicate BE (Beaded Element) notations.
  • Click to select, or drag to multi-select.
  • Edits apply to all selected positions.

Bead structures

Core only
A bead threaded onto the core thread at this picot. No picot loop.
Core + plain picot
Core bead(s) plus a standard un-beaded picot loop above.
Core + beaded picot
Core bead(s) plus a picot loop that itself carries beads.
Suspended
Beads string hang from the picot, held up by a closing bead.
Beaded picot
Only the picot has beads.

Connectable join point TOGGLE

A toggle to let a BE (Beaded Element) behave like a Join picot. In Join Picot mode these will be selectable, and can connect to one or more other joined picots.
Copy / Cut / Paste
  • Behaves as the Clipboard, just for the Beaded elements.

Dropdowns

Select the desired beads to apply to the selected elements.
Edit the available beads using the 'Library...' button.

Tatting Order Mode

Entered via View → Tatting Order… Exit via 'Exit mode' button or ESC.
Dragging, multi-select, and notation editing are all disabled — click elements to select them one at a time and assign sequence numbers.

Mode Banner Row
Round dropdown
Assign "rounds" to elements. Placing them in a separate group makes organizing repetitive patterns easier. Editing the names of rows or deleting them is possible within the dropdown. When an element assigned to a group, it will change the color of the order number.
Progress counter
Shows {numbered} / {total} numbered — updates live as you work. Counts all elements including lines (lines can carry order numbers too).
Hint text
Reminds you to select an element to assign its number. Disappears once an element is selected.
✕ Exit Mode
Exits Tatting Order Mode and returns to the normal property bar.
Exit warning
If any elements are still unnumbered when you exit, a message tells you how many.
Number Assignment Row (appears when an element is selected)
Order # input
Pre-filled with the element's current number if it already has one. Type any positive integer and press Enter or click the ↵ button to assign. Cleared automatically when you click a different element.
↵ (submit)
Assigns the typed number to the selected element. Disabled while the field is empty or non-numeric. If the number is already taken by another element, the Conflict popup appears.
Assign Next
One-click shortcut that assigns the next available gap number — the lowest positive integer not yet used by any element. The button label shows the number that will be assigned so you can confirm before clicking.
Assign to Group
Assigns the selected element to the selected Group.
Clear
Removes the order number from the selected element entirely. Disabled if the element has no number.
Current # badge
Small gold #N badge shown next to Clear when the element already has a number — quick confirmation of what's assigned.
Canvas behaviour in this mode
Pink glow
All elements without an order number glow pink at all times while the mode is active. Glow disappears as soon as a number is assigned.
Gold / Group colored numbers
Assigned order numbers appear as colored labels at the midpoint of each element — rings at their center, chains and lines at the arc midpoint. Ungrouped elements show in gold. Elements assigned to a round use that round's color.
No dragging
Elements cannot be moved while this mode is active. Clicks select; nothing drags. Exit the mode first to reposition elements.
Gray R badge
Elements marked as Repeat show a gray R badge instead of a number. They are treated as assigned (no pink glow, not counted as unnumbered) but do not appear in the pattern output. Use this for motifs you work multiple times without needing a separate order number — for example, repeating rings 1–6 four times.
Keyboard Shortcuts (element selected, cursor not in a text field)
N
Assigns the next available number to the selected element — same as clicking the Assign Next button.
R
Marks the selected element as Repeat. Shows a gray R badge; element is excluded from pattern output but treated as assigned.
Delete / Backspace
Clears the order assignment from the selected element (number or repeat mark). Same as clicking the Clear button.
PgUp
Switches to the next round. On the last round, creates a new one.
PgDn
Switches to the previous round; from the first round, back to Ungrouped.
Conflict Popup (amber border)
Appears when you try to assign a number that is already in use by another element.
Swap
The selected element gets the entered number; the element that previously held it gets the selected element's old number. Grayed out if the selected element has no existing number — there is nothing to swap to.
Shift all higher numbers up
The selected element gets the entered number. Every element with a number equal to or higher than the entered number is incremented by one to make room. Gaps in the existing sequence are preserved.
Cancel
Dismisses the popup. Nothing changes — the selected element keeps its previous number (or stays unnumbered).
SVG Export
Order Numbers layer
When any element has an order number, SVG export adds a dedicated Order Numbers layer (Inkscape/Illustrator compatible). Each number is a gold text element with a black outline, positioned at the element midpoint. The layer can be hidden or deleted in a vector editor without affecting the pattern artwork.

🧹 Clean Up Duplicates
Triggered by File → Clean Up Duplicates…, and automatically after saving or opening a file.

Shows how many overlapping duplicates were found (same notation, material, rotation and position) and asks whether to remove them. Clean Up removes them as one undoable step; Cancel leaves everything as it is. When run from the menu and nothing is found, it says so.

💍 Convert to Josephine Knot
Triggered by the third Shape button on a ring.

Warns that all picots and connections will be removed and the stitches will change from ds to ss. Convert to JK or Cancel.

✏ Notation Change
Appears when a notation edit would remove joined picots.

Some joined picots will no longer exist after the change, so their connections would be removed. Change Notation or Cancel. For a multi-selection you're asked once.

🚀 Splash Screen
Shown when the app starts.
New Project
Starts with an empty canvas.
Load Project
Opens the Recent Projects dialog.
Resume
"Resume: {name}" reopens the last autosave. Shows "No Autosave" when there isn't one.
Getting Started
Tips, with arrows for the previous and next tip.
Update check
"Have you checked for updates?" — click it for Open Releases Page or Dismiss for this version.
ℹ About Dialog
Triggered by Help → About TattingCAD.

Shows the app logo, version, description, license, GitHub button, Ko-fi button, and a manual update check.
The Open Releases Page button opens GitHub.

🎨 Color Picker
Used for element colors, material colors, background color, and polar grid colors.
Color Picker tab
Saturation / brightness square, hue slider, base swatches and hex input.
DMC Colors tab
Searchable DMC thread color database. Search by name or number, or filter by category (All, or a color group).
Lizbeth Colors tab
The same browser for Lizbeth thread colors.
Gradients tab
